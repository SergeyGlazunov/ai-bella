# Будущие доработки

Обновлено: 2026-10-29. Это список работ и результаты анализа, не отчёт о внедрении.

Действующий порядок: [работа со стендом и Git](../production-workflow.md). Текущий приоритет — исправлять рабочий контур и сохранять проверенные изменения. Состояния анализа ниже относятся к ранее собранным материалам и требуют сверки перед реализацией.

Очередность:

1. Уточнить и внедрять небольшими изменениями улучшения MCP и Open WebUI Tools, затем проверить стабильность стенда.
2. Мониторинг сохранить как отложенную спецификацию. Сейчас не реализовывать.
3. После стабилизации вернуться к установщику и универсальному комплекту.

Для MCP сначала использовать уже существующие настройки, затем делать подтверждённые изменения кода. Выпуск на стенд отдельным шагом, с фиксацией образа/версии и проверкой tools/list и tools/call. Наличие исходников в Git не доказывает, что стенд запускает тот же код.

Материалы стенда прочитаны локально из D:/contour_gpt/mcp-review-input/mcp-review-input. Сырые ответы, адреса пользователей, служебные файлы и выгрузки кода автоматически в Git не переносятся. Перед реализацией MDD/SDMS/Confluence нужны проверенные исходники в репозитории с указанием происхождения; конфигурации стенда сохранять без секретов, с указанием назначения.

Подробный план и реализация MCP начнутся после согласования исправленных требований. Ни развёртывание, ни изменение данных бизнес-систем этим документом не разрешены.
