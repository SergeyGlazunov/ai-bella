# Пакет задания для Cursor

Исходники проекта уже находятся на рабочей машине Cursor. Эта папка содержит
только документы, подготовленные для аудита и будущей миграции.

## Порядок чтения

1. `../docs/superpowers/specs/2026-10-18-installable-contour-design.md` — контракт продукта, вектор, алгоритм правки. Новая работа идёт отсюда, не с Task 1.
2. `AGENT.md`
3. `LINUX-FIRST-DESIGN.md` — операционный приоритет ночи. Вектор контракта продукта выше.
4. `LINUX-FIRST-IMPLEMENTATION-PLAN.md` — история миграции оркестратора. Задачи заново не начинать.
5. `PRE-GIT-CLEANUP-AUDIT.md`
6. `CURRENT-STATE-AUDIT.md`
7. `DEVELOPMENT.md`
8. `USER.md`

`TECHNICAL-AUDIT.md` используется как справочная карта старой копии. Он не
является актуальным источником правды.

## Задание

Сопоставь эти документы с проектом на своей машине. Сначала выполни read-only
инвентаризацию и зафиксируй отличия. Не копируй старые файлы поверх более новых
без сравнения.

Затем сверяй новую работу с контрактом продукта, а не начинай `LINUX-FIRST-IMPLEMENTATION-PLAN.md` с Task 1. План — история миграции оркестратора. Не работай с живым стендом без отдельного разрешения. Не помещай секреты в Git.

Приоритет — вектор в контракте продукта: чистая установка и верная ночь. Не реализуй защитное замечание, если оно не ломает установку, штатный цикл, восстановление или сохранность рабочих данных.

Если фактическое окружение расходится с контрактом продукта, останови затронутый шаг и сообщи о расхождении. Шаблон под эту машину не подгонять: отличие стенда записывается в контракт, раздел «Один репозиторий».

Факты стенда — `../STATUS.md`. Переустановка живого стенда не является следующей задачей.
