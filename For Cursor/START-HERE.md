# Пакет задания для Cursor

Исходники проекта уже находятся на рабочей машине Cursor. Эта папка содержит
только документы, подготовленные для аудита и будущей миграции.

## Порядок чтения

1. `AGENT.md`
2. `LINUX-FIRST-DESIGN.md`
3. `LINUX-FIRST-IMPLEMENTATION-PLAN.md`
4. `PRE-GIT-CLEANUP-AUDIT.md`
5. `CURRENT-STATE-AUDIT.md`
6. `DEVELOPMENT.md`
7. `USER.md`

`TECHNICAL-AUDIT.md` используется как справочная карта старой копии. Он не
является актуальным источником правды.

## Задание

Сопоставь эти документы с проектом на своей машине. Сначала выполни read-only
инвентаризацию и зафиксируй отличия. Не копируй старые файлы поверх более новых
без сравнения.

Затем выполняй `LINUX-FIRST-IMPLEMENTATION-PLAN.md` последовательно, начиная с
Task 1. После каждой задачи запускай указанные проверки и делай отдельный
commit. Не работай с живым стендом без отдельного разрешения. Не помещай
секреты в Git.

Если фактическое окружение расходится с документацией, останови затронутый
этап, зафиксируй read-only inventory и сообщи о расхождении. Этапы 6 и 7
являются опциональными.

Без доступа к целевой машине итог формулируется так: «реализация и локальная
проверка завершены; развёртывание и cutover ожидают проверки на стенде».
