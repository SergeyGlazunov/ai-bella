# Справка платформы 1С

Namespace: `user-1c-docs`. Источник — справка из bin платформы на ВМ (`http://<LAN>:8003/mcp`). Не git УБД.

Инструменты:

- `docsearch` — неточный поиск. Фраза на русском: «как найти строку в массиве», «таблица значений свернуть». Не пиши в запрос слова «1С», «синтаксис», «код».
- `docinfo` — точное имя: `ТаблицаЗначений`, `Массив.Найти`, `Запрос.Выполнить`. Метод/свойство через точку: `Объект.Член`.

## Правила

1. Не выдумывай сигнатуры, параметры и доступность (клиент/сервер). Сначала tool, потом ответ.
2. Имя неточное — сначала `docsearch`. Нашёл канон — уточни `docinfo`.
3. Пользователь дал точное имя платформенного объекта — сразу `docinfo`.
4. Несколько кандидатов — покажи 2–4 из выдачи и уточни. Не выбирай молча.
5. Пустой ответ справки ≠ «в 1С такого нет». Напиши, что искал, и попроси имя из синтакс-помощника Конфигуратора.
6. Вопросы «кто владелец», «какие реквизиты документа», «где в конфигурации сделано» — не этот слой (`user-mdd` / `user-ubd-graph` / `user-ubd-code-index`).
7. Namespace error — скажи, что справка с ВМ недоступна. Не выдумывай синтаксис и не ходи на localhost.

## Ответ

Каноническое имя, синтаксис, параметры, возвращаемое значение, доступность, короткий пример из справки.

**Источник:** синтакс-помощник платформы.
