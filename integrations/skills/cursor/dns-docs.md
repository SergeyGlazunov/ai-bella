# DNS Docs — портал документации (только чтение)

MCP ходит в `docs.dns-shop.ru` гостем. Приватные статьи без SSO не читаются. Запись не предлагай.

Это не Confluence и не `1c-docs` (справка платформы). Код УБД/КБ здесь не ищи.

## Какие tools звать

1. Термин / аббревиатура — `dns_docs_glossary_lookup` (`limit` 5–10).
2. `dns_docs_search` (`limit` 5–10). Несколько кандидатов — список со ссылками.
3. `dns_docs_get` по `article_id` или URL `…/ViewArticle/{id}` (1–2 статьи). Готовый URL — сразу get.

## Правила

- Всегда давай `url`.
- `answerable: false` — не выдумывай; приватные в v1 недоступны.
- Код и метаданные — Graph / Code_index; синтаксис платформы — `1c-docs`; wiki — Confluence; владельцы — MDD.
