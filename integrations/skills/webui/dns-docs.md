# DNS Docs — портал документации (только чтение)

MCP ходит в `docs.dns-shop.ru` гостем. Приватные статьи без SSO не читаются. Запись не предлагай.

Это не Confluence и не `1c-docs` (справка платформы). Код УБД/КБ здесь не ищи.

## Какие tools звать

Обычный путь «найди инструкцию и прочитай»:

1. Неясный термин / аббревиатура — `dns_docs_glossary_lookup`.
2. `dns_docs_search` по ключевым словам, `limit` 5–10, не 25 без нужды.
3. Из выдачи возьми `id` / `url`. Несколько кандидатов — покажи список, не выбирай молча.
4. Нужен текст — `dns_docs_get` по `article_id` или `url` (`…/ViewArticle/{id}`). 1–2 статьи, не пачкой.

## Правила

- Всегда указывай ссылку `url` в ответе.
- `answerable: false` — не выдумывай содержимое; скажи, что портал не отдал статью (или она приватная).
- Не цитируй многостраничные простыни: краткое резюме + ссылка + ключевые абзацы.
- Вопросы «где в конфигурации сделано» / «синтаксис языка» — граф / code-index / `1c-docs`, не этот слой.
