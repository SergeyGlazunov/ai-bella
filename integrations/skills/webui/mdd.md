# MDD — портал метаданных

MDD отвечает на вопросы «чей объект» и «какие служебные свойства висят на портале». Это не конфигуратор и не git.

Инструменты:

- `available_metadata_properties` — справочник имён свойств
- `metadata_owners` — владельцы
- `metadata_properties` — доп. свойства

Фильтр `names` — точные полные имена через запятую. Подстрока, синоним и фраза из чата туда не подходят. Сначала нормализуй имя, потом зови инструмент.

Не вызывай граф, code-index и справку 1С на вопросах этого слоя.

Пользователю нельзя показывать план и «сейчас найду». Первое действие — `view_skill` (если скилла ещё нет) и один `metadata_owners`. Текст — только после `ДанныеОтвета`. Пакет максимум 8 имён, один вызов, не пачка по одному. Пустое сообщение после рассуждения — ошибка.

## 1. Разбор фразы

Выдели два куска:

- **подсказка типа** — «хттп сервис», «справочник», «рег сведений», «общий модуль»
- **токен имени** — «Лебовски», «номенклатура», «дисбалансы»

Запрос «расскажи про X» = паспорт объекта: владельцы + ключевые свойства. Не отказывай только потому, что не сказано слово «владелец».

## 2. Тип → канон MDD

| Как написали | Тип в MDD |
|---|---|
| справочник, catalog | Справочник |
| документ, document | Документ |
| регистр сведений, РС | РегистрСведений |
| регистр накопления, РН | РегистрНакопления |
| регистр бухгалтерии | РегистрБухгалтерии |
| ПВХ, план видов характеристик | ПланВидовХарактеристик |
| отчёт, report | Отчет |
| обработка, data processor | Обработка |
| перечисление, enum | Перечисление |
| общий модуль, common module | ОбщийМодуль |
| план счетов | ПланСчетов |
| http-сервис, хттп сервис, http service | HTTPСервис |
| веб-сервис, web-сервис | WebСервис |
| ws-ссылка | WSСсылка |
| константа | Константа |
| подписка на событие | ПодпискаНаСобытие |
| регламентное задание | РегламентноеЗадание |
| роль | Роль |
| форма | не тип корня; уточни объект-владелец формы |

Если тип двусмыслен («сервис») — в один вызов клади и `HTTPСервис`, и `WebСервис`. Тип не указан — не угадывай десять вариантов; 2–3 самых вероятных.

## 3. Токен → пакет имён

Собери варианты и склей в один `names` через запятую. Один вызов, не пачка по одному. Не больше 8 имён.

Правила:

1. Как есть: `HTTPСервис.Лебовски`
2. Нижний регистр латиницы: `HTTPСервис.lebowski`
3. Транслит RU→EN (ё→e, х→h и kh, й→y, ю→yu, я→ya, ж→zh, ч→ch, ш→sh)
4. Пробелы и дефисы → ничего и → `_`
5. Префикс `dns_` и `dns` (локальное соглашение): `HTTPСервис.dns_lebowski`
6. Если пользователь уже дал `Тип.Имя` — этот вариант первым

Пример для «хттп сервис Лебовски»:

`HTTPСервис.Лебовски,HTTPСервис.lebowski,HTTPСервис.Lebowski,HTTPСервис.dns_lebowski,HTTPСервис.dns_Lebowski,WebСервис.dns_lebowski`

Синоним без совпадения с идентификатором MDD не найдёт. Это не повод писать «объекта не существует».

## 4. Как читать ответ

Смотри `ДанныеОтвета`, не только `Сообщение`.

- `Сообщение` = «Объект не обнаружен», но массив не пустой → объект найден, бери `ИмяМетаданного`.
- Несколько строк → покажи все совпадения и уточни. Не выбирай молча.
- Пустой `ДанныеОтвета` → не «на портале нет». Напиши, какие имена искал; попроси имя из конфигуратора (`HTTPСервис.dns_…`).

Канон для следующих вызовов — только `ИмяМетаданного` из ответа.

## 5. Владельцы и свойства

| Поле | Смысл |
|---|---|
| ИмяМетаданного | канон |
| Направление | бизнес-направление |
| ОтветственныйФилиал | владелец (филиал) |
| ОтветственныйФилиалПочта | почта |
| ITФилиалыПоддержки | массив: Наименование + Почта |
| Родитель | пустая строка — норма |

Пустая дата подтверждения ≠ «владельца нет».

Свойства:

1. Фильтр — сначала `available_metadata_properties`, ключи из поля `Имя`.
2. `metadata_properties` с уже каноническим именем.
3. Полный паспорт — `names` без `properties`.

Частые свойства: `ДатаПодтвержденияВладения`, `ДатаПодтвержденияАктуальностиОбъекта`, `Классификация`, `КоммерческаяТайна`, `КоличествоСтрок`, `ВсегоЗанято`, `Использовано`, `РазмерКодовойБазы`, `SQLНаименованиеТаблицы`.

«Кто владелец» → только `metadata_owners`.
«Расскажи про» / актуальность / «кому отдать» → владельцы + эти свойства.

«Кому отдать»: не предлагай «куда угодно». Если пользователь назвал соседей — сними их владельцев тем же инструментом. Данных мало — скажи, чего не хватает.

## 6. Формат ответа

```
**Объект:** HTTPСервис.dns_lebowski
**Как искали:** «хттп сервис Лебовски» → пакет имён
**Источник:** MDD

| Роль | Значение |
|---|---|
| Направление | … |
| Ответственный филиал | … (почта) |
| IT-поддержка | … (почта) |

**Оговорки:** что пусто в MDD.
```
