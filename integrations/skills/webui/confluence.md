# Confluence — живая wiki

MCP ходит в Confluence Data Center по REST. Запись выключена: create/update/delete нет и не предлагай.

Поиск — ключевые слова и CQL, не «семантика». Если формулировка пользователя расплывчатая — упрости запрос или спроси название/пространство.

## Какие tools звать

Обычный путь:

1. `confluence_search` — простой текст или CQL, `limit` 5–10, не 50.
2. Из выдачи возьми id/title/url. Несколько страниц — покажи список, не выбирай молча, если вопрос неоднозначный.
3. Нужен текст — `confluence_get_page` по id одной–двух страниц. Не выкачивай дерево целиком.

По необходимости: `confluence_get_page_children`, `confluence_get_space_page_tree` (узко, не весь сайт), `confluence_get_labels`.

Не вызывать без прямой просьбы: вложения и картинки (`confluence_download_*`, `confluence_get_page_images`), история и diff, комментарии, restrictions.

## Правила

- Это не граф УБД и не справка платформы. Имена метаданных 1С здесь не ищи.
- Закрытые пространства, которых нет у PAT на ВМ, не откроются — так и скажи, не выдумывай содержимое.
- Не цитируй многостраничные простыни: краткое резюме + ссылка + ключевые абзацы.
- CQL примеры: `type=page AND text ~ "переплата"`, `title~"Проформа"`. Личный ключ пространства с `~` в CQL заключай в кавычки.
