# Ошибки развёртывания (не повторять)

Журнал для агента и человека при **повторной** установке ai2 / graph-стека.
Источник: живой стенд и `DEVELOPMENT.md` комплекта AI-Contour. Без секретов.

Полный установочный набор tools: SDMS, Confluence, Graph, Code_index, MDD,
query-builder + skills (`integrations/skills/`). Этот каталог — **Graph** и
**query-builder** (Neo4j). Code_index — `compose/bsl-indexer`. Чат-слой —
`compose/ai-stack`. Overlays ai2 — `deploy-ai2/`.

---

## Сети и DNS

| Симптом | Причина | Что делать |
|---|---|---|
| Prod и ai2 в одной docker-сети, `getent hosts neo4j` отдаёт два IP | Base compose задаёт `networks.default.name: 1c-suite-net`. Второй стек получает алиас `neo4j` в той же сети | Для ai2 — **отдельная** сеть (`ai2-mcp-ubd_net` / `ai2-mcp-kb_net` и т.п.). Не подключать ai2-neo4j к `1c-suite-net` |
| Карточки WebUI не видят MCP | Контейнер не в сети чата или в URL `127.0.0.1` | URL внутри Docker: `http://<имя-контейнера>:<порт>/mcp`. Сеть чата на стенде: `ai2-stack` / `ai-stack_default` — только осознанно |
| Новый ai2 «прилип» к prod WebUI-сети | override монтировал `ai-stack_default` | В комплекте override **без** prod-сети. Чат: `docker-compose.webui.yml` + `WEBUI_NETWORK`, или `docker network connect` |
| query-builder не поднимается на ai2 | раньше был `profiles: unused` в overlays | Канон: `up -d … mcp-query-builder`; порты УБД `:8109`, КБ `:8209` |

## Neo4j

| Симптом | Причина | Что делать |
|---|---|---|
| Neo4j `unhealthy` часами, Browser на `:7474` жив | Healthcheck через `cypher-shell` (полная JVM) с коротким timeout; процесс зависает, Docker помечает unhealthy | В override ai2: healthcheck HTTP `wget` на `http://127.0.0.1:7474` |
| MCP отвечает `neo4j_unavailable`, хотя Neo4j Up | Дефолтный probe ~3 с; под GC ответ дольше → кеш «недоступен» на десятки секунд | `NEO4J_HTTP_TIMEOUT_SEC=30…90`, `NEO4J_PROBE_TIMEOUT_SEC=15…45` |
| Exit 137 у Neo4j / indexer | OOM: uncapped heap на ВМ | В override: heap initial/max 1g/2g, pagecache 1g |
| Пароль из `.env` «не применяется» | `NEO4J_AUTH` работает только при **первой** инициализации тома | Смена: `cypher-shell` `ALTER CURRENT USER SET PASSWORD…` или новый том |
| Переменная `NEO4J_PASSWORD` в environment сервиса neo4j ломает старт | Образ трактует `NEO4J_*` как настройки конфига | Для healthcheck — имя **без** префикса `NEO4J_` (например `HC_NEO4J_PASSWORD`) |

## Compose / индексация

| Симптом | Причина | Что делать |
|---|---|---|
| `docker compose up -d` уходит в полную переиндексацию на часы | `mcp-metadata-graph` зависит от `metadata-indexer`; изменилась выгрузка | Поднять серверы: `up -d --no-deps mcp-metadata-graph mcp-query-builder …`. Indexer — явно |
| После правки кода `restart` «не подхватил» | `restart` не меняет образ | `build` + `up -d --force-recreate --no-deps <сервис>` |
| Watcher жрёт диск / тянет полный прогон | На Windows bind-mount → polling; watcher не обновляет fingerprints | На стендах `WATCHER_ENABLED=false`; обновление — `apply_changes.py` |

## Open WebUI

| Симптом | Причина | Что делать |
|---|---|---|
| MCP в Docker есть, в чате карточки нет | Список в SQLite: `config.tool_server.connections`, не в `.cursor/mcp.json` | Править `webui.db`, затем `docker restart` контейнера WebUI |
| GET на `/mcp` даёт 406 | Норма для Streamable HTTP без MCP-сессии | Пугать должен timeout / connection refused, не 406 |
| Слишком много tools → OmniRoute режет | Порог ~64 tools на модель | В карточке `function_name_filter_list` — короткий список |

## Секреты и клиенты

| Симптом | Причина | Что делать |
|---|---|---|
| Серверы не стартуют, код 78 | Пустой `MCP_SHARED_SECRET` или `NEO4J_PASSWORD` | Заполнить `.env` из `.env.example` |
| 401 на все tools | Секрет в карточке / mcp.json ≠ `.env` | Сверить bearer; после смены `.env` — recreate контейнеров |
| Скрипты с хоста 503, `curl` ок | Системный HTTP-прокси Windows гонит localhost в прокси | `NO_PROXY=localhost,127.0.0.1` |

## Что сознательно убрано из комплекта

- **OpenCode** (`opencode-config.json`, корневой Dockerfile/entrypoint, сервис compose) — не входит в установочный набор ai2. Клиент — Open WebUI (+ Cursor по желанию).
- Архив «заходов» (`PLAN-*`, `СТАТУС`, `ОТКРЫТОЕ`, `PROMPTS`, `КУДА-КЛАСТЬ`) — не операционка.

Журнал решений комплекта: корневой `DEVELOPMENT.md` репозитория AI-Contour.
