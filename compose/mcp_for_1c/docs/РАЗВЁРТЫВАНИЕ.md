# Развёртывание Graph + query-builder

Короткая инструкция для комплекта AI-Contour / стенда ai2.
Грабли, которые уже чинили: [ОШИБКИ-РАЗВЁРТЫВАНИЯ.md](ОШИБКИ-РАЗВЁРТЫВАНИЯ.md).
Устройство — [ARCHITECTURE.md](../ARCHITECTURE.md). Полный README каталога —
[README.md](../README.md).

## Что ставится вместе с этим каталогом

| Tool | Откуда |
|---|---|
| Graph | этот compose: Neo4j + `mcp-metadata-graph` + `metadata-indexer` |
| query-builder | этот compose: `mcp-query-builder` |
| Code_index | `compose/bsl-indexer` + `deploy-ai2/bsl-*` |
| MDD / SDMS / Confluence | отдельные live MCP |
| Skills | `integrations/skills/webui/` (импорт в Open WebUI вручную) |
| Чат | `compose/ai-stack` (Open WebUI + OmniRoute) |

Overlays двух графов (УБД / КБ): `deploy-ai2/mcp_for_1c-ubd/`,
`deploy-ai2/mcp_for_1c-kb/`. Эталон нового сервера — `deploy-ai2/README.md`.

Транспорт MCP: **Streamable HTTP, `/mcp`, stateless**.

## Требования

- Docker (на стенде — Engine в WSL2 Ubuntu)
- Память ВМ: ориентир ≥16 ГБ при двух графах + WebUI + BSL
- XML-выгрузка на **ext4** (`/srv/ai2/ubd/src`, `/srv/ai2/kb/src`), не DrvFs
- Python 3.10+ на хосте — только для проверочных скриптов

## Подъём graph (один инстанс)

```powershell
Copy-Item .env.example .env
# MCP_SHARED_SECRET, NEO4J_PASSWORD, WORKSPACE_DIR=<путь к выгрузке>
```

```powershell
docker compose build
docker compose up -d neo4j mcp-metadata-graph mcp-query-builder
```

К чату (опционально, после подъёма):

```powershell
# WEBUI_NETWORK=ai-stack_default (prod) или ai2-stack
docker compose -f docker-compose.yml -f docker-compose.override.yml `
  -f docker-compose.webui.yml up -d mcp-metadata-graph mcp-query-builder
```

Индексация — отдельно, когда есть `Configuration.xml`:

```powershell
docker compose run --rm metadata-indexer
```

С overlays ai2 (пример УБД):

```bash
docker network create ai2-mcp-ubd_net   # один раз
docker compose -p ai2-mcp-ubd \
  -f docker-compose.yml \
  -f docker-compose.override.yml \
  -f docker-compose.ai2.yml \
  up -d neo4j mcp-metadata-graph mcp-query-builder
```

Не поднимайте второй стек в сеть `1c-suite-net` рядом с prod — получите
двойной DNS `neo4j` (см. ОШИБКИ). К prod `ai-stack_default` не цеплять
из `docker-compose.override.yml` — только через `docker-compose.webui.yml`
или `docker network connect`.

## Подключение Open WebUI

Карточки — в SQLite WebUI (`tool_server.connections`), URL вида
`http://<контейнер>:<порт>/mcp`, контейнер в сети чата. После правки БД —
`docker restart` WebUI. Чеклист новой карточки — в README каталога,
раздел «Подключение Open WebUI».

## Обновление выгрузки

Частично (минуты):

```powershell
docker compose run --rm --entrypoint python metadata-indexer /app/apply_changes.py --dry-run
docker compose run --rm --entrypoint python metadata-indexer /app/apply_changes.py
```

Полный прогон — только если `apply_changes` отказался или долг резолва велик.
Не делайте голый `docker compose up -d` «на всякий» — он может зацепить
indexer на часы. Серверы без зависимостей: `up -d --no-deps …`.

## Если не работает

Сначала таблица в [ОШИБКИ-РАЗВЁРТЫВАНИЯ.md](ОШИБКИ-РАЗВЁРТЫВАНИЯ.md), затем:

```powershell
docker compose ps
docker compose logs --tail=50 neo4j
docker compose logs --tail=50 mcp-metadata-graph
```

Пустой `MCP_SHARED_SECRET` / `NEO4J_PASSWORD` → код выхода 78.
`answerable: false` / `graph_empty` — граф ещё не проиндексирован, не «объекта нет».
